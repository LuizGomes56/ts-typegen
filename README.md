# Rodar a extensão
- Abrir os dois arquivos typegen de cada projeto
- Rodar o comando `ts-typegen.generateOutput`
- Arquivos serão gerados em dbrules.

- Caso um erro ocorra, faça um `CTRL + SHIFT + P` e use `reload window`, depois espere o `tsc` terminar de fazer a análise dos arquivos e rode o comando novamente
